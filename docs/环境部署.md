# 环境部署需求

这一页是给**需要手工搭环境**（或想搞清楚为什么装这么多东西）的人看的。
跑 `scripts\setup_runtime.ps1` 的话，下面这些它全都会做，不用手抄。

> **为什么不打包环境**：Python + torch 光这两样就 **12.9 GB**，其中 torch 一个占 **9.3 GB**（CUDA 11.8 的 cuBLAS / cuDNN / cuRAND 全塞在 torch 自己的 `lib\` 里）。代码本体只有 **111 KB**。把 12.9 GB 塞进仓库或 Release 既传不动，也没必要——下面给了精确版本，装出来和我打包的完全一致。

---

## 一、总览：四个隔离环境

| 环境 | 位置 | Python | 谁在用 | 装完体积 |
|---|---|---|---|---|
| **A 主程序** | `runtime\py312\` | 3.12.7 | 启动脚本、向导、自检、识图判断、声纹、浮窗 | **5,540 MB** |
| **B 语音推理** | `runtime\py39\` | 3.9.13 | GPT-SoVITS 变声（TTS） | **6,598 MB** |
| **C 声卡** | `envs\sd_env\` | 借用 A | 录音采集、播放 | 3 MB |
| **D 语音识别** | `envs\sv_env\` | 借用 B | SenseVoice ASR、CAM++ 声纹 | 3 MB |

C / D 不是独立解释器，只是用 `pip --target` 装出来的**包目录**，运行时靠 `sys.path` 注入。所以删掉它们不影响 A / B。

---

## 二、系统前置

| 项 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10 / 11 **x64** | 只在 x64 上测过 |
| 显卡 | NVIDIA，**驱动 ≥ 452.39** | CUDA 11.8 的运行库由 torch 自带，**不需要另装 CUDA Toolkit** |
| 显存 | **8 GB 可用**（实测 RTX 4060 Ti） | 变声 + 识图 + ASR 同时驻留 |
| 磁盘 | **SSD**，留 20 GB 以上 | 机械盘会让模型加载慢到不可用（实测 5400 转上 1.3 GB 模型要 44 秒） |
| VC++ 运行库 | 一般不用装 | `runtime\py312\` 自带 `vcruntime140.dll` / `vcruntime140_1.dll` |
| ffmpeg | **不用装** | `runtime\py39\ffmpeg.exe` 已自带（50.5 MB） |
| 声卡 | Voicemeeter Banana + VB-CABLE | 见 `docs\安装与配置.md` §5；虚拟声卡用来做「AI 听到的是通话里对方的声音，而不是自己的喇叭」 |

## 三、环境 A：`runtime\py312\`（主程序）

### 3.1 解释器

**Python 3.12.7 x64**（python.org 官方安装包）。

参数要点：

```
python-3.12.7-amd64.exe /quiet InstallAllUsers=0 TargetDir=<项目>\runtime\py312 ^
    Include_pip=1 Include_tcltk=1 Include_test=0 Include_launcher=0 Shortcuts=0
```

- `Include_tcltk=1` — **必须**，桌面浮窗用 tkinter
- `Include_test=0` — `Lib\test` 有 27 MB，用不上
- `TargetDir` 必须指到项目内，**不要装进系统**

### 3.2 pip 包（实测版本，可直接照抄）

| 包 | 版本 | 用途 |
|---|---|---|
| **torch** | **2.7.1+cu118** | 识图判断模型推理 |
| **numpy** | **2.4.6** | 矩阵运算 |
| pillow | 11.3.0 | 截图编码、浮窗图片 |
| **dxcam** | 0.3.0 | 独占全屏截图（GDI 截不到独占全屏） |
| comtypes | 1.4.17 | dxcam 依赖 |
| transformers | 5.8.0 | laya 依赖 |
| safetensors | 0.5.3 | 权重加载 |
| huggingface_hub | 1.26.0 | 下载/缓存模型 |
| **laya** | **0.3.23** | 识图判断模型运行时 |
| soundfile | 最新 | 音频读写 |

安装：

```powershell
$PY = "<项目>\runtime\py312\python.exe"

& $PY -m pip install --upgrade pip
& $PY -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu118
& $PY -m pip install numpy pillow soundfile dxcam comtypes transformers safetensors huggingface_hub laya
```

> **必须用 `& $PY -m pip`，不要直接敲 `pip`** —— 后者会装进系统 Python。

体积：torch 5,168 MB，其余合计约 372 MB。

### 3.3 只要 CPU 版怎么办

把第二条换成：

```powershell
& $PY -m pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
```

torch 从 5,168 MB 降到约 200 MB，整个环境 **5.5 GB → 0.6 GB**。
代价：识图判断和一切 py312 侧的模型推理退回 CPU，每句话多几百毫秒到几秒。
`setup_runtime.ps1 -CpuOnly` 就是干这个的。

## 四、环境 B：`runtime\py39\`（GPT-SoVITS 变声）

GPT-SoVITS 要求 **Python 3.9 / 3.10**（3.11 以上 torchaudio 的 API 会变），所以只能用老解释器。

### 4.1 解释器

**Python 3.9.13 x64**，同样 `TargetDir=<项目>\runtime\py39`、`Include_test=0`。
`Include_tcltk` 可以不勾（这一侧不弹窗）。

### 4.2 pip 包（实测版本）

先装 torch 三件套：

```powershell
$PY9 = "<项目>\runtime\py39\python.exe"

& $PY9 -m pip install torch==2.0.0 torchaudio==2.0.0 torchvision==0.15.1 `
    --index-url https://download.pytorch.org/whl/cu118
```

再装 GPT-SoVITS 官方依赖（脚本 `setup_gpt_sovits.ps1` 会把这两个文件一起拿下来）：

```powershell
& $PY9 -m pip install -r "<项目>\gpt-sovits\api\requirements.txt" `
                         -r "<项目>\gpt-sovits\api\extra-req.txt"
```

核心版本（照抄）：

| 包 | 版本 | 备注 |
|---|---|---|
| torch / torchaudio / torchvision | 2.0.0+cu118 / 2.0.0 / 0.15.1 | 三个版本互相强绑定，不能单独升 |

| transformers | 4.43.0 | GPT-SoVITS 锁的版本 |
| onnxruntime_gpu | 1.19.2 | 部分模型走 onnx |
| librosa / numba / scipy | 0.9.2 / 0.56.4 / 1.9.3 | |
| pyopenjtalk | 0.3.4 | 日文分词 |
| mecab_python3 / mecab_ko_dic / eunjeon | 1.0.10 / 1.0.0 / 0.4.0 | 日/韩文处理 |
| jieba / jieba_fast / pypinyin / cn2an | 0.42.1 / 0.53 / 0.50.0 / 0.5.22 | 中文处理 |
| g2p_en / g2pk2 / LangSegment / fast_langdetect | 2.1.0 / 0.0.3 / 0.3.5 / 0.3.1 | 多语种 |
| nltk / wordsegment | 3.8.1 / 1.3.1 | |

## 五、环境 C：`envs\sd_env\`（声卡）

```powershell
& $PY -m pip install --target "<项目>\envs\sd_env" --no-deps `
    soundcard==0.4.6 sounddevice==0.5.6
```

| 包 | 版本 | 用途 |
|---|---|---|
| **soundcard** | **0.4.6** | **主力**：走 WASAPI，能真的从 Voicemeeter 虚拟端点拿到声音 |
| sounddevice | 0.5.6 | 备用（走 PortAudio） |

> **为什么主力是 soundcard 不是 sounddevice**：PortAudio 打开 Voicemeeter 虚拟端点会"成功"，但取到的音频**全是静音**——实测 RMS `0.00000`，同一时刻 soundcard 是 `0.27~0.34`。所以用 sounddevice 会表现为「程序在跑、ASR 一直无输入」。

`--no-deps` 是有意的：soundcard 的依赖已经在 py312 主环境里了，不重复装。

## 六、环境 D：`envs\sv_env\`（语音识别）

```powershell
& $PY9 -m pip install --no-deps --target "<项目>\envs\sv_env" funasr==1.1.18
```

| 包 | 版本 | 用途 |
|---|---|---|
| **funasr** | **1.1.18** | SenseVoice-Small 语音识别 + CAM++ 声纹 |

> **为什么要单独隔离**：`runtime\py39\` 里**自带 funasr 1.0.27**（GPT-SoVITS 装的），它的 SenseVoice 接口和新版 checkpoint 不兼容，直接跑会报形状/字段错误。装 1.1.18 到独立目录，运行时 `sys.path.insert(0, envs\sv_env)` 抢到优先级，就能用新版。
>
> `--no-deps` 也是必须的：funasr 会想装一整套自己的 torch，装进来就是第二份 4 GB。这里**故意不装依赖**——注入 `sys.path` 后，funasr 用的仍然是 py39 那份 torch 2.0.0。
>
> 结果：`envs\sv_env\` 里只有 `bin\`、`funasr\`、`funasr-1.1.18.dist-info\`，**没有 torch**，整个目录 3 MB。

## 七、为什么非得四个环境（版本冲突矩阵）

| 冲突点 | 环境 A 要 | 环境 B 要 | 结论 |
|---|---|---|---|
| numpy | 2.4.6 | **1.23.4**（numba 0.56.4 上限） | 装不进同一个环境 |
| torch | 2.7.1（laya 要求 transformers ≥ 4.48） | **2.0.0**（torchaudio/torchvision 强绑定） | 差 7 个大版本 |
| funasr | — | **1.1.18**（自带的是 1.0.27，不兼容 checkpoint） | 必须隔离 |
| 声卡包 | 只需要 `soundcard` | 不需要 | 隔离，避免升级主程序时把音频弄坏 |

硬要合成一个环境，唯一的路是把 torch 降到 2.0.0 + numpy 降到 1.23，那样 laya 装不上，识图判断就没了。

## 八、落位与注入（不污染系统）

整套东西**不写系统 PATH、不写注册表、不动系统 Python**，全靠代码里指定：

- `src\util\paths.py` 里 `ROOT = Path(__file__).resolve().parents[2]`
- `inject(env_dir)` → `sys.path.insert(0, str(env_dir))`
- `child_env(extra)` → 起子进程时把 `PYTHONPATH` / `PYTHONHOME` 指向内置解释器

所以**删掉整个文件夹 = 卸载干净**。

## 十、不用脚本、纯手工

1. 按 §3.1 / §4.1 把两个 Python 装进 `runtime\py312`、`runtime\py39`
2. 按 §3.2 / §4.2 装 pip 包（**顺序别换**：先 torch 再其余）

4. 按 `docs\安装与配置.md` §3 放 GPT-SoVITS 代码，§4 放模型
5. 按 §9 四条命令逐条验证
6. 跑 `配置.bat` 填 API Key，再跑 `启动.bat`

## 十二、常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| `torch.cuda.is_available()` 是 `False` | 装成了 CPU 版，或显卡驱动 < 452.39 | 看 `torch.version.cuda`，为 `None` 就按 §3.2 重装；否则升级驱动 |
| `ImportError: DLL load failed while importing _C` | 缺 VC++ 2015-2022 运行库 | 装 [vc_redist.x64](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| `pip` 装完在系统 Python 里找不到、项目里也没有 | 直接敲了 `pip` 而不是 `& $PY -m pip` | 永远用绝对路径的 `python.exe -m pip` |
| py39 里 `numpy` 变成 2.x，numba 报 `attribute 'int' has no attribute ...` | 被别的包升上去了 | `& $PY9 -m pip install "numpy==1.23.4"` |
| ASR 一直没输入、RMS 恒为 0 | 用了 sounddevice 打开虚拟端点 | 确认走 soundcard（§5） |
| `funasr` 报 checkpoint 字段/形状不匹配 | `envs\sv_env` 没被注入，跑到自带的 1.0.27 了 | 确认 `sys.path` 顺序，`envs\sv_env` 在 `runtime\py39\Lib\site-packages` 之前 |
| `soundcard` 报找不到设备 | VoiceMeeter 没启动 | 先开 Voicemeeter Banana |
| 模型加载特别慢 | 项目放在机械盘 | 整个项目挪到 SSD |
