# 安装与配置

这份文档解决一件事：**从零把这套装起来，让它出声。**
每一步都写了"为什么"和"怎么验证做对了"，照做就行。

---

## 0. 先说清楚：哪些东西要你自己下

仓库里**只有代码**。下面这些因为体积或许可原因，不进仓库，需要你自己准备：

| 类别 | 要下的东西 | 体积 | 必需性 |
|---|---|---|---|
| 运行时 | Python 3.12 + torch(cu118)、Python 3.9 + torch 2.0、funasr、soundcard | ~12 GB | 必需 |
| 代码 | GPT-SoVITS 推理代码 | ~0.7 GB | 必需（用变声就要） |
| 模型 | SenseVoice-Small（语音识别） | ~0.9 GB | 必需 |
| 模型 | GPT-SoVITS 基座权重 | ~4.2 GB | 必需（用变声就要） |
| 模型 | 角色音色权重（自己训） | 视情况 | 必需（用变声就要） |
| 模型 | CAM++（声纹） | ~29 MB | 只在开声纹校验时要 |
| 模型 | Laya 微调版（判断要不要看屏幕） | ~2.0 GB | 只在不手动指定识图时 |
| 模型 | Qwen3-VL-4B（本地识图，可选） | ~8.3 GB | 除非不用云端识图 |
| 软件 | Voicemeeter Banana + VB-CABLE | 44 MB | 要走虚拟声卡就要（**仓库 vendor 目录已带**） |
| 软件 | NVIDIA 驱动 | — | 有 N 卡就要，版本 ≥ 452.39 |
| 软件 | Git | — | 只在"源码部署"这种方式下需要 |
| 软件 | QQ NT | — | 只在"接电话"模式下需要 |

> 仓库和 Release 都**不含运行时**：Python + torch 光这两样就 9.3 GB（CUDA 库占大头），
> 放不进 git，也不值得占 Release 配额。运行时用下面第 2 步的脚本现装，装进项目内，
> 删项目就等于卸载，不污染系统。

## 1. 硬件与系统前置

- Windows 10 / 11，64 位。**不支持 Linux / macOS**（用到 WASAPI 音频、窗口自动化、DPI 相关 API）。
- 磁盘：纯代码版约 15 GB（含运行时和模型）；完整包约 17 GB。放在 SSD 上，别放机械盘——模型加载会慢到不可用（实测 5400 转盘上 1.3 GB 模型要 44 秒）。
- 内存：16 GB 起。8 GB 也能跑，但开本地识图会吃紧。
- GPU：NVIDIA 显卡。**没有独显也能跑**，只是 TTS 会慢到每句话几秒到十几秒。
  - 驱动版本要支持 CUDA 11.8（R452.39 以上，建议直接装最新）。
  - 怎么验证：`nvidia-smi` 能看到显卡和驱动版本即可。

## 2. 拿到项目并装运行时

```powershell
git clone https://github.com/SeaSmall/Elaina_SoVITS.git
cd Elaina_SoVITS
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup_runtime.ps1
```

`setup_runtime.ps1` 会做三件事：装一份 Python 3.12 到 `runtime\py312`、装一份 Python 3.9 到 `runtime\py39`、
把 torch / transformers / soundcard / funasr 装进对应位置。全程约 12 GB 下载，视网速 20 分钟到 2 小时。

> 如果国内下载慢，先设镜像再跑：
> ```powershell
> $env:HF_ENDPOINT='https://hf-mirror.com'
> $env:HF_HUB_DISABLE_XET='1'      # 不加这条，镜像会 401
> $env:PIP_INDEX_URL='https://pypi.tuna.tsinghua.edu.cn/simple'
> ```

## 3. 放 GPT-SoVITS 代码（方式 B 需要，方式 A 跳过）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup_gpt_sovits.ps1
```

它会把上游仓库 clone 下来，把需要的部分拷到 `gpt-sovits\api\`：
`api_v2.py`、`GPT_SoVITS\`（**不含** `pretrained_models`）、`tools\i18n\`、`config.py`、`LICENSE`。

然后手动下基座权重，放进 `gpt-sovits\api\GPT_SoVITS\pretrained_models\`，需要这几个子目录：

| 子目录 | 文件 | 说明 |
|---|---|---|
| `chinese-roberta-wwm-ext-large\` | `pytorch_model.bin`（651 MB） | 中文文本特征 |
| `chinese-hubert-base\` | `pytorch_model.bin`（189 MB） | 语音特征 |
| `s1bert25hz-2kh-longer-epoch=68e-step=50232.ckpt`（155 MB） | — | GPT 基座 |
| `v2Pro\s2Gv2ProPlus.pth`（200 MB） | — | SoVITS 基座（v2ProPlus） |
| `sv\pretrained_eres2netv2w24s4ep4.ckpt`（108 MB） | — | 声纹特征 |
| `fast_langdetect\lid.176.bin`（131 MB） | — | 语种检测 |

总计约 4.2 GB。GPT-SoVITS 的 release 页面有打包好的压缩包，也可以直接从那边下。

## 4. 放 AI 模型

把下好的模型放进对应目录。**目录里直接就是模型文件，不要再套一层文件夹。**

```
model\
├─ asr\           ← SenseVoice-Small
├─ campplus\      ← CAM++（开声纹校验才要）
├─ laya\          ← Laya 微调版
└─ vlm\           ← Qwen3-VL（用本地识图才要）
```

### 4.1 SenseVoice-Small（语音识别，必需）

- **ModelScope**：<https://modelscope.cn/models/iic/SenseVoiceSmall>
  ```powershell
  pip install modelscope
  modelscope download --model iic/SenseVoiceSmall --local_dir model\asr
  ```
- **或 HuggingFace**：<https://huggingface.co/FunAudioLLM/SenseVoiceSmall>
  ```powershell
  set HF_ENDPOINT=https://hf-mirror.com
  set HF_HUB_DISABLE_XET=1
  huggingface-cli download FunAudioLLM/SenseVoiceSmall --local-dir model\asr
  ```

体积约 940 MB，里面应该是 `model.pt`、`config.yaml`、`tokens.json` 这类文件。

> 许可提醒：SenseVoice 官方要求**注明出处、作者信息并保留模型名称**。本项目的
> `licenses\THIRD_PARTY_LICENSES.md` 已经写好这段署名，别删。

### 4.2 CAM++（声纹，可选）

- ModelScope：<https://modelscope.cn/models/iic/speech_campplus_sv_zh-cn_16k-common>

```powershell
modelscope download --model iic/speech_campplus_sv_zh-cn_16k-common --local_dir model\campplus
```

约 29 MB。放好之后运行 `录声纹.bat` 录几段自己的声音，它会把阈值自动标定好。

### 4.3 Laya 微调版（要不要看屏幕的判断模型）

这个不是公开发布的模型，是 `convaiinnovations/laya-multilingual` 的微调派生版，
由项目作者单独提供。拿到后放进 `model\laya\`。

**不想要自动判断也行**：把 `config\config.json` 里 `vision.gate` 改成：
- `always` —— 每句话都看屏幕（简单粗暴，多花 token）
- `never` —— 从不看屏幕（最省）
- `off` 配合 `vision.mode = "off"` —— 完全关掉识图

这个模型的作用是：每句话都先问它一次「用户这句话需不需要看屏幕」，单次前向约 30~120 ms，
只输出一个概率，不生成文本。比让大模型自己判断快得多也便宜得多。

### 4.4 GPT-SoVITS 角色权重（变声必需）

放在 `gpt-sovits\weights\GPT_weights_v2ProPlus\`（`.ckpt`）和
`gpt-sovits\weights\SoVITS_weights_v2ProPlus\`（`.pth`），需要**成对**使用
（GPT 权重负责语气韵律，SoVITS 权重负责音色，两个必须同一套训练出来的）。

```
gpt-sovits\
├─ api\                          ← GPT-SoVITS 推理代码（第 3 步）
├─ weights\                      ← 你自己放
│   ├─ GPT_weights_v2ProPlus\    *.ckpt
│   └─ SoVITS_weights_v2ProPlus\ *.pth
└─ README-放代码.txt
```

然后再准备一段 5~10 秒的参考音频（`.wav`），以及**这段音频里逐字对应的文字**。
参考音频决定音色、语气和情绪——GPT-SoVITS 没有任何"情绪参数"，情绪只能从参考音频来。

> ⚠ 仓库**不提供**任何角色音色权重。GPT-SoVITS 项目本身是 MIT 许可，但那只覆盖**代码**；
> 用某个角色形象 / 某位声优的声音训出来的权重能不能再分发，不属于开源许可的授权范围。

### 4.5 Qwen3-VL（本地识图，可选）

- <https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct>（约 8.3 GB，8 GB 显存勉强）
- 有 16 GB 显存可以用 8B 版

放进 `model\vlm\`，然后把 `config\config.json` 里 `vision.mode` 改成 `"local"`。
不装的话默认走云端识图（`mimo-v2.6-pro`），不占显存也不占包体积。

## 5. 装软件

### 5.1 虚拟声卡（走语音通话/游戏陪玩必需）

仓库 `vendor\` 里已经带了安装包：

| 文件 | 是什么 |
|---|---|
| `VoicemeeterProSetup_v2130.exe` | Voicemeeter Banana 2.1.3.0 |
| `VBCABLE_Setup_x64.exe` | VB-CABLE 虚拟声卡 |
| `VBCABLE_ControlPanel.exe` | VB-CABLE 控制面板 |

**先装 Voicemeeter，再装 VB-CABLE，装完都要重启。** 安装时允许驱动签名提示。

> 这两个都是 VB-Audio 的 **donationware**，可以免费分发但作者靠捐赠维持开发。
> 觉得好用请去 <https://vb-audio.com/Services/licensing.htm> 捐赠。
> 完整的分发声明见 `licenses\VB-AUDIO-NOTICE.txt`。

⚠ 不要用 Voicemeeter **Potato** —— 官方明确要求它在 webshop 购买授权，
不在可自由分发的范围内，本项目也不适用 Potato 的路由设置。

### 5.2 NVIDIA 驱动

<https://www.nvidia.cn/Download/index.aspx> 装最新 Game Ready 或 Studio 驱动都行。
关键验证：装完能在命令行跑 `nvidia-smi`，并且 CUDA Version 显示 ≥ 11.8。

### 5.3 QQ（只用"接电话"模式才需要）

- **必须是 QQ NT 桌面版**（新版 QQ），<https://im.qq.com>
- 需要**在本机登录着**你的 QQ 号
- 需要**交互式桌面**（远程桌面断开、锁屏、服务会话下都抓不到窗口）
- 屏幕缩放建议设成 **100%**，非 100% 时自动接听会去换算坐标，成功率下降

> 自动接听的原理是**截屏 + 找绿色接听按钮 + 模拟点击**，不是 QQ 官方 API。
> 个人号做窗口自动化违反 QQ 用户协议，有封号风险，请自行判断是否使用。
> 换 QQ 版本、换皮肤、换缩放比例都可能让它失效——失效时用 `--no-answer` 手动接。

## 6. 配配置

### 6.1 用向导（推荐）

双击 `启动.bat`。第一次会进向导，**只问缺的那几项**：选模型服务商、填 API Key、
（可选）现在录声纹。填完自动保存到 `config\config.json`，然后直接进对话。

要重新配：双击 `配置.bat`，或 `启动.bat --wizard`。

### 6.2 手改 config.json

`config\config.json` 结构（字段说明）：

```jsonc
{
  "mode": "local",              // local = 本机麦克风/音箱；qq = 走 QQ 通话
  "lang": "zh",                 // 对话语言

  "persona": {
    "name": "Elaina",
    "system_prompt": "..."      // 人设。想换角色改这里
  },

  "llm": {
    "provider": "deepseek",     // deepseek | mimo | mimo-anthropic | custom
    "base_url": "https://api.deepseek.com/v1",
    "api_key": "sk-...",        // ★ 你自己的 key，不要提交到 git
    "model": "deepseek-chat",
    "temperature": 0.8,
    "max_tokens": 800,
    "timeout": 60
  },

  "translation": {              // 日文模式才用
    "enabled": false,
    "use_main_llm": true,       // true = 翻译也走上面那个模型，不用另配
    "target_lang": "ja"
  },

  "vision": {                   // 识图
    "mode": "off",              // off | cloud | local
    "gate": "auto",             // auto(Laya判断) | always | never
    "provider": "mimo",
    "base_url": "https://token-plan-cn.xiaomimimo.com/v1",
    "api_key": "",              // 云端识图的 key，可以和主模型不同
    "model": "mimo-v2.6-pro",
    "reasoning_effort": "none", // ★ 必须 none，否则每张图多等 20 秒
    "max_width": 1920,
    "max_tokens": 4000
  },

  "asr": {
    "mode": "local",
    "url": "http://127.0.0.1:9881",
    "lang": "auto"              // auto | zh | en | ja | yue
  },

  "tts": {
    "enabled": true,
    "url": "http://127.0.0.1:9880",
    "ref_audio": "",            // 参考音频绝对路径或相对项目根的路径
    "prompt_text": "",          // 参考音频里逐字对应的文字
    "prompt_lang": "zh",
    "text_lang": "zh"
  },

  "voiceprint": {
    "enabled": false,           // 开了就只认录声纹的那个人
    "threshold": 0.35
  },

  "audio": {
    "input": "",                // 留空 = 系统默认；也可写设备名的一部分
    "output": ""
  },

  "history_turns": 20           // 带多少轮历史给模型
}
```

### 6.3 去哪拿 API Key

| 服务商 | 地址 | 默认模型 | 备注 |
|---|---|---|---|
| DeepSeek | <https://platform.deepseek.com/api_keys> | `deepseek-chat` | 便宜，中文好 |
| 小米 MiMo | MiMo 开放平台（token-plan） | `mimo-v2.6-flash` | 识图用 `mimo-v2.6-pro` |
| 自建 / 其他 | 任何 OpenAI 兼容服务 | 自己填 | ollama、vLLM、one-api 都行 |

> `base_url` 填到 `/v1` 就行，程序会自动补 `/chat/completions`。
> MiMo 还有个 Anthropic 协议入口 `https://token-plan-cn.xiaomimimo.com/anthropic`，
> 把 `provider` 填 `mimo-anthropic` 就会走那套协议。

## 7. 音频路由（local 模式）

local 模式最简单：**什么都不用设**，直接用系统默认麦克风和默认扬声器。

要走虚拟声卡（比如让 AI 的声音被另一个软件当麦克风收走）：

1. 打开 Voicemeeter Banana，把硬件输入选成你的麦克风，硬件输出选成你的耳机/音箱
2. Windows 声音设置里，把**默认播放设备**设成 `VoiceMeeter Input`
3. 把**默认录音设备**设成 `VoiceMeeter Output`
4. 在 `config\config.json` 的 `audio.input` / `audio.output` 里写设备名的一部分，
   比如 `"output": "VoiceMeeter Input"`

> ⚠ 音频库必须用 `soundcard`，不能用 `sounddevice`。实测 `sounddevice` 打开
> VoiceMeeter 虚拟端点能成功但**完全没声音**（RMS 0.00000，而 soundcard 是 0.27~0.34）。
> 项目已经把 `soundcard` 打进 `envs\sd_env` 并在启动时注入，别改。

## 8. 验证装对了

按顺序跑这几条，哪条断了就知道卡在哪：

```powershell
# 1) 整体自检（缺什么会直接列出来）
runtime\py312\python.exe scripts\check.py

# 2) 大模型通不通
runtime\py312\python.exe src\main.py --selftest

# 3) 当前配置长什么样（key 已打码）
runtime\py312\python.exe src\main.py --print-config

# 4) 问一句话就退出（不进循环）
runtime\py312\python.exe src\main.py --once "在吗"
```

`check.py` 的输出里：
- `[ OK ]` 没问题
- `[WARN]` 缺了也能跑，但相关功能不可用（比如没放模型）
- `[FAIL]` 必须补，否则启动会停

## 9. 常见问题

**双击 `启动.bat` 一闪就没了**
在项目目录按 Shift + 右键 → 在此处打开 PowerShell，手动跑 `.\启动.bat`，就能看到报错。

**中文全是乱码**
`.bat` 必须是 UTF-8 **无 BOM** + CRLF，配合 `chcp 65001`。加了 BOM 第一行命令会失效。
如果你改过 bat，注意别让编辑器给你加 BOM。

**`--selftest` 报 401 / 403**
key 错了或过期。注意 `Bearer` 后面不要有空格、不要带引号。

**`--selftest` 报 404**
`base_url` 填错了。填到 `/v1` 为止，别自己加 `/chat/completions`（加了也能认，但别加两次）。

**有声音但不像那个角色**
参考音频不对。GPT-SoVITS 的音色和情绪**完全由参考音频决定**，没有任何参数能调。
换一段更接近目标语气、5~10 秒、干净的音频，并把 `prompt_text` 逐字对上。

**TTS 特别慢**
八成是没走 GPU。跑这条确认：
```powershell
runtime\py39\python.exe -c "import torch; print(torch.cuda.is_available())"
```
输出 `False` 说明驱动或 CUDA 没配好。

**自动接听不工作**
先跑 `--dry` 看能不能找到来电窗口。常见原因：QQ 没登录、屏幕缩放不是 100%、
QQ 是旧版不是 NT 版、锁屏了。应急用 `--no-answer` 手动接。

**模型放好了但 check.py 还说没有**
目录里是不是只放了 `放模型说明.txt`？`check.py` 会忽略说明文件，必须有真实模型文件。

## 10. 许可与隐私

- 你不会在任何文件里看到别人的 key、别人的声纹、别人的账号。仓库里也没有。
- 你自己的 `config\config.json`、`data\voiceprint\` 已经在 `.gitignore` 里，别提交。
- 第三方组件的完整许可见 `licenses\` 目录。
- 不随包分发：角色音色权重、参考音频、GPT-SoVITS 基座权重、任何人的声纹。
